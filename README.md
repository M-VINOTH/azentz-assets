# Azentz Assets

Public, non-sensitive Azentz brand assets.

## Structure
- email/ - email-safe logo variants
- brand/ - primary brand assets
- icons/ - favicon and Apple touch icon

## Public URL convention
https://assets.azentz.com/<path>

Example:
https://assets.azentz.com/email/azentz-logo.png

Do not store user photos, album files, customer data, secrets, or private application assets here.
